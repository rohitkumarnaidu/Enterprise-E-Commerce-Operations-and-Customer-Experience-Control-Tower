# 🖥️ Power BI `.pbix` Manual Build Guide
## Enterprise E-Commerce Operations & Customer Experience Control Tower

> **Why this file exists:** The `.pbix` binary cannot be generated by code — it must be built manually in Power BI Desktop.  
> **Time required:** ~2–3 hours for full build  
> **Prerequisites:** Power BI Desktop installed (free from Microsoft Store or powerbi.microsoft.com)

---

## 🔵 STEP 1 — Create a New Power BI Report

1. Open **Power BI Desktop**
2. Click **File → New** (blank report)
3. Save immediately: **File → Save As**
   - Filename: `ecommerce_operations_control_tower.pbix`
   - Save location: `power_bi/` folder in your project

---

## 🔵 STEP 2 — Set Up the FolderPath Parameter

This makes all your data connections portable (no hardcoded paths).

1. Click **Home → Transform Data → Transform Data** (opens Power Query Editor)
2. In Power Query Editor: **Home → Manage Parameters → New Parameter**
3. Fill in:
   - **Name:** `FolderPath`
   - **Type:** Text
   - **Required:** ✅ checked
   - **Current Value:** `C:\PROJECTS\Data Analytics\E-Commerce\data\processed\`
     *(Include the trailing backslash `\`)*
4. Click **OK**

> ⚠️ The path must end with `\` and point to your `data/processed/` folder exactly.

## 🔵 STEP 10 — What-If Parameter (SLA Simulator)

1. **Modeling tab → New Parameter**
2. Settings:
   - Name: `Target SLA`
   - Data type: Decimal Number
   - Minimum: `0.70`
   - Maximum: `1.00`
   - Increment: `0.01`
   - Default: `0.95`
3. Click **OK** — Power BI creates the parameter table and a slicer automatically
4. Create this measure in `_Measures`:
```dax
Orders Needed to Hit Target =
VAR TargetRate = SELECTEDVALUE('Target SLA'[Target SLA], 0.95)
VAR Delivered = [Delivered Orders]
VAR OnTime   = [On-Time Delivered Orders]
RETURN MAX(0, ROUNDUP(TargetRate * Delivered - OnTime, 0))
```
5. Add a **Card** visual with `Orders Needed to Hit Target` on Page 2

## 🆘 Common Issues & Fixes

| Problem | Fix |
|---|---|
| "Column not found" error on refresh | Check `FolderPath` parameter ends with `\` |
| Date table not working for time intelligence | Right-click `DimDate` → Mark as Date Table → select `full_date` |
| Relationship creates circular dependency | Make one of the duplicate date relationships **Inactive** |
| Scatter chart shows only 1 dot | Move `seller_id` to **Details** field well (not Legend) |
| Decomposition Tree shows no splits | The analyze field must be a numeric measure, not a column |
| What-If slider not appearing | Check parameter table is loaded (Enable Load = ON) |
